# Aion 2 Timers

Alertas de bosses e eventos do **Aion 2** (servidor América do Sul) para Android. O app funciona offline e guarda tudo no próprio celular.

> App de fã, **não oficial**, sem vínculo com a NCSOFT.

## Instalar
1. Abra a [última versão](https://github.com/bennu-forge/aion2-timers/releases/latest) no celular e baixe o arquivo `.apk`.
2. Abra o arquivo baixado e permita "instalar apps desconhecidos" quando o Android pedir.

## Atualizar
O próprio app avisa quando sai uma versão nova (tela **Agora** ou **Ajustes → Atualizações**). Toque em **Atualizar** e depois em **Instalar**.

O Android só aceita a atualização se ela tiver a mesma assinatura do app instalado, e o app confere o SHA-256 do arquivo antes de instalar.

Este repositório contém só os APKs publicados.
